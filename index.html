What is this?

Anti Emo is a Lua-based script for The Strongest Battlegrounds — a fast-paced anime PvP fighting game on Roblox with over 17 billion visits, developed by Yielding Arts.

Anti Emo fucks everything that moves. If it doesn't, he'll force it.

Features
Aim Lock
Silent aim with multiple modes — Instant, Lerp, Aggressive, Snap, Hybrid, Spiral and more
Prediction
Velocity & movement-based prediction for accurate tracking
No Collision
No Collision / No Collision+ — bypass hitbox collision
Velocity Modification
Full control over your movement velocity
Cooldown Bars
Visual cooldown tracker for dashes and evasives
Trusting System
Part-based trust control for precise target management
Mobile API
Full mobile support with touch aim lock
UI Settings
Full theme customisation and save manager
